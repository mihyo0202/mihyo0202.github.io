# Portfolio Website — Phạm Đình Minh Hiếu

Trang web cá nhân 3 section theo yêu cầu môn **Nhập môn Công nghệ số và Ứng dụng Trí tuệ nhân tạo**.

## Cấu trúc

| Section | Nội dung |
|---------|----------|
| **1. Hero & About** | Banner full-width, ảnh profile, grid 4 sở thích/mục tiêu |
| **2. Projects** | Bento grid 6 bài thực hành (Từ Bài 1 - Bài 6) với nội dung theo đúng rubric |
| **3. Reflection** | Split-screen: ảnh workspace + trải nghiệm, kiến thức, điểm tâm đắc & thách thức |

## Cấu trúc thư mục Assets cần thiết

Hãy đảm bảo bạn xếp các ảnh/tài nguyên đúng theo đường dẫn:

* `assets/hero-circuit.svg` (File background SVG của bạn)
* `assets/images/profile.jpg` (Ảnh chân dung của bạn)
* `assets/images/workspace.jpg` (Góc bàn làm việc)
* `assets/images/trello-board.png` (Hình minh hoạ Trello cho Bài tập 4)
* `css/styles.css`
* `js/main.js`

## Mở trang web

Mở file `index.html` bằng trình duyệt (double-click hoặc Live Server).
